# Bacola - Fullstack E-Commerce Platform

Dự án website thương mại điện tử hoàn chỉnh được xây dựng với kiến trúc Client-Server tách biệt, tập trung vào việc áp dụng các best practices trong lập trình Spring Boot hiện đại và giao diện React.js.

## 🏗️ Kiến trúc dự án

Dự án được phân chia thành 3 phần độc lập:

- `/server`: RESTful API backend xây dựng bằng Java / Spring Boot & database PostgreSQL, MongoDB.
- `/client`: Ứng dụng web dành cho khách hàng duyệt sản phẩm, giỏ hàng và thanh toán.
- `/admin`: Cổng quản trị dành cho Admin quản lý đơn hàng, danh mục và người dùng.

## 🚀 Công nghệ cốt lõi

- **Backend:** Spring Boot, Spring Security, Spring Data JPA, PostgreSQL, MapStruct, Lombok, Gradle.
- **Frontend:** React.js, Modern JavaScript, REST API integration.
